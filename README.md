# Micrograd

A scalar-valued autograd engine built from scratch in Python.
Implements backpropagation over a dynamically built DAG.

## What it does
- Builds a computation graph automatically
- Performs forward and backward passes
- Trains a simple neural network from scratch

## Built with
Pure Python (no PyTorch, no NumPy)

## Inspired by
Andrej Karpathy's micrograd lecture
